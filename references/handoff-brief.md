# Creative Brief Template

Use this template when the skill cannot produce the asset directly. Fill every section; incomplete briefs lead to rejected drafts and wasted iterations.

```markdown
## Asset Brief

### Deliverable
- **Type:** photo / illustration / video / audio / animation / 3D model
- **Format:** (e.g., PNG 4000×2667 @ 300 DPI, MP4 H.264 1080p 30fps, WAV 48kHz 24-bit)
- **Quantity:** (number of assets or variations)
- **Deadline:** (date)
- **Budget:** (if commissioning)

### Content Description
- **Subject:** (what is shown)
- **Action/scene:** (what is happening, if applicable)
- **Setting/environment:** (where)
- **Mood/tone:** (e.g., calm, energetic, professional, playful)
- **Color palette:** (hex codes or reference swatches)

### Technical Constraints
- **Dimensions/aspect ratio:** (e.g., 16:9, 4:5, print size)
- **Transparency required:** yes/no
- **Safe margins:** (for print or platform UI overlap)
- **File size limit:** (if applicable)
- **Codec/compatibility:** (if video/audio)

### Style Reference
- **Inspiration:** (links to examples, "like this but not this")
- **Explicit avoid:** (styles, colors, or elements to exclude)

### License and Usage
- **Intended use:** (commercial, editorial, internal, client work)
- **Territory:** (global, regional)
- **Duration:** (perpetual, campaign period)
- **Attribution:** (required or not)

### Notes
- (Anything else the creator needs to know)
```

## When to Use

- The asset requires live-action video production.
- The asset needs an original music composition or voiceover recording.
- The asset requires brand-specific photography or a commissioned illustration style.
- No free stock source matches the subject, and AI generation quality is insufficient.
- The user explicitly prefers to work with a human creator.
