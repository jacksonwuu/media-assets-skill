# Source Selection

## Decision Order

1. Project-owned assets: check existing libraries and prior downloads first.
2. Public-domain or permissive licenses: use when reuse flexibility matters.
3. Attribution-required licenses: use when attribution can be supplied consistently.
4. Paid or account-gated sources: use only when the user confirms access and billing.
5. Original creator channels: use when the user can identify the desired creator.

## Source Matrix

| Medium | Useful starting points | Access | License notes |
| --- | --- | --- | --- |
| Photos | Unsplash, Pexels, Wikimedia Commons, Flickr search, Openverse | Direct/API where available | Check each source and individual upload; some licenses require attribution |
| Illustrations/vectors | Openverse, SVG Repo, unDraw, Wikimedia Commons, creator sites | Direct/API where available | Verify commercial, modification, and attribution terms |
| Video | Pexels, Pixabay, Coverr, NASA Image and Video Library, Wikimedia Commons | Direct/API where available | Check redistribution and commercial-use terms |
| Audio/music | Free Music Archive, Jamendo, ccMixter, Freesound, YouTube Audio Library | API/direct download where available | Distinguish CC-BY, CC0, sampling, and noncommercial clauses |
| Icons | Lucide, Heroicons, Tabler, Phosphor, Font Awesome | Docs/package assets | Most are permissive; confirm brand/icon naming rules |
| Fonts | Google Fonts, Fontsource, Font Squirrel, Open Font Library | API/package/direct | OFL and Apache licenses are common; check embedding/redistribution clauses |
| 3D | Poly Haven, Sketchfab, Smithsonian Open Access, itch.io | API/direct where available | Confirm texture licensing separately from model licensing |

## Search Strategy

- Translate the brief into 3–7 precise search phrases before browsing; include medium, subject, action, setting, lighting, color, mood, and era where relevant.
- Start broad enough to learn vocabulary, then narrow with metadata filters: orientation, dimensions, duration, codec, license, creator, category, and color.
- Prefer sources with stable IDs, canonical URLs, and complete metadata.
- Cross-check reused or republished material against the original source before accepting it.
- Record the query and filters used so the search can be resumed or expanded.
